# Foundry demo

A static demo of Foundry, a bounty board over GitHub for Zenon work:
https://foundry-demo.zenon.foo/

Everything on it is simulated. There is no board behind the page: every figure,
person, task and payout comes from a snapshot of a development instance, under
`demo/`, and nothing you do is saved. The people (`dev-ada` and the others) and
the treasury addresses are placeholders with no key behind them. Do not send
anything to an address shown here.

This repository is a build, not source. It was made once, on 2026-10-13, from
the Foundry source with `npm run demo` in its `web/` directory.
